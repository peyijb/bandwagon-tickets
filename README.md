## 搬瓦工客服能帮你处理哪些问题

搬瓦工卖的是 **Unmanaged（非托管型）VPS**，官方说明写得很清楚：商家只负责宿主机和底层基础设施，不负责帮你安装、配置软件，也不负责帮你排查 VPS 内部的应用问题。

以下这些属于客服**会**处理的范畴：

- IP 被封（检测到封禁后，可以申请换 IP 或迁移机房）
- 付款成功但 VPS 没有开通
- VPS 突然无法开机（宿主机层面的问题）
- 续费账单、退款申请（30 天内、流量用量低于 10% 可退）
- 账户问题（邮箱修改注意：需要 5 天后才生效）

以下这些，客服**基本不会插手**：

- 帮你装 SS/SSR、V2Ray 等软件
- 排查你 VPS 内部的程序报错
- 优化网络配置

搞清这个边界，工单里就不会写废话，回复也会更快。

## FAQ：搬瓦工工单常见问题

**Q：搬瓦工工单回复速度一般多久？**
A：工作日通常 24 小时以内，快的话 1 小时左右。周末不工作，周六、周日提的单要等到周一。

**Q：提工单要用中文还是英文？**
A：必须用英文。中文客服看不懂，会影响处理效率。实在不会写，复制到百度翻译翻一遍直接粘贴提交即可。

**Q：工单被 Martin C 机器人回复了怎么办？**
A：把你的原始问题重新复制一遍，再回复到同一工单里，就会进入人工客服流程。不要另开新工单，否则你的排队顺序会往后推。

**Q：搬瓦工有没有在线聊天或电话客服？**
A：没有。只有工单系统和邮件（support@bandwagonhost.com）两种方式，目前不提供电话支持。

**Q：周末急着解决问题怎么办？**
A：先看看 KiwiVM 控制面板能不能自助解决——重启 VPS、迁移机房、重装系统这些操作都不需要工单。真的需要客服介入的，只能等到周一。
